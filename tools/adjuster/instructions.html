Adjuster instructions

Review and correct hydrologic time series, with original measurements and an editable correction history.

Download Adjuster (.zip, 687 KiB)Open Adjuster in browser

Run locally

  1. Download and unzip the folder. Keep it somewhere convenient, then open Adjuster.html in a current desktop browser. No server or runtime installation is required. Chrome or Edge supports the direct project-folder workflow.
  2. Create a folder for your watershed or monitoring network inside projects/. Choose Create / open project folder in Adjuster and select it. Grant read/write access when the browser asks.
  3. Import CSV, TSV or Campbell TOA5 files. Map timestamp and measurement columns, units, datum and time offset. Import each station or measurement as a separate series. The import Destination menu can append strictly later readings; import overlapping data or historical backfill as a separate series.
  4. Select an interval, preview a correction, enter a reason and apply. Applied edits and undo/redo save automatically. Wait for each operation to finish before closing the application. A preview is not a saved edit.

Explore the examples

Choose an example on the project screen to generate a fresh editable project. Each has two editable stations, independent field observations, reference data and completed corrections. All measurements and calibration evidence are synthetic.

  • Well record: drift, datum offsets, manual depth checks, interpolation, missing observations and absent timestamps. Corrected depth can also be exported as water-level elevation.
  • Stream stage: calibration, reference reconstruction, quality review and an illustrative bounded stage–discharge rating for S01. The tributary gage S03 has its own corrections and starts with stage-only export.

Example notes explains the corrections and selects their intervals. The download also contains original CSVs, known simulated values, completed exports for both editable stations and compressed project backups.

Navigate the record

Use 1d / 7d / 30d / All, or enter both dates and choose Show dates. Drag across the plot to select an interval, then choose Zoom to selection. Double-click to zoom in; Shift double-click zooms out. With the plot focused, + / − zoom and left/right arrows pan. Switching stations retains an overlapping time window and selects matching field readings.

Save and export

Export produces corrected CSVs with original values, quality flags and provenance. Export backup produces a complete .adjuster.gz project containing all records, original imports and correction history. Restore into a new empty folder. Legacy .adjuster.json projects can also be migrated.

Adjuster creates and manages project.json, data/ and history/. Keep the entire project folder together. Close the app before copying or syncing it, and use one editor per folder. Keep independent backups; autosave is not a backup.

Browser storage and large projects

If folder access is unavailable, choose Create browser project. Browser storage is specific to the browser and website/local-file context and may be cleared or evicted. Export backups regularly, or use Copy to project folder in a supported browser. Placing an HTML file next to a folder does not grant it write permission.

Wide plots show sampled extrema and gaps; corrections and exports use all records. The storage engine has been tested with three million records across three stations. Performance depends on the computer, browser, available storage and edit history. Browsers without a direct save picker buffer downloads and limit each export to 256 MiB.
